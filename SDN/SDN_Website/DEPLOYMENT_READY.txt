TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Issue: Cannot start servers
  → Check if ports 5000 and 8000 are available
  → Run: lsof -i :5000 and lsof -i :8000
  → Kill existing processes if needed

Issue: API connection failed
  → Verify API server is running (should see logs in terminal)
  → Check http://localhost:5000/api/health in browser
  → Verify firewall isn't blocking localhost

Issue: WebSocket not connecting
  → Check browser console (F12) for errors
  → Verify API server is running
  → Try refreshing the page
  → WebSocket should fallback to polling automatically

Issue: Attacks not appearing
  → Click "Launch Attack" button (wait 2-3 seconds)
  → Check browser console for errors
  → Verify network connection is active
  → Refresh the page

For more help: See README.md Troubleshooting section
