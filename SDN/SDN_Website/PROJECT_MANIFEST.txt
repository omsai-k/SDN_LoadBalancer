================================================================================
KNOWN LIMITATIONS
================================================================================

1. Data is Simulated
   - All network statistics use random values
   - No connection to real SDN controller
   - Perfect for demonstrations and testing

2. Charts are Placeholders
   - Chart areas show placeholder text
   - Can be enhanced with Chart.js or similar

3. Settings Don't Persist
   - Configuration changes aren't saved
   - Would require backend database

4. No Real Authentication
   - Logout button is non-functional
   - Would need authentication system

5. No WebSocket Real-time Updates
   - Stats update via JavaScript intervals
   - Could be enhanced with live websockets
